# Churn Risk Analyzer


## Тестовые данные

После запуска загрузите набор кейса с демонстрационными сценариями:

```bash
docker compose exec backend python manage.py load_sample --extended
```

Без `--extended` загружается только набор из кейса. Подробнее о наборах, сдвиге дат
и сценариях — в [sample-data/README.md](sample-data/README.md).
