# Тестовые и демонстрационные данные

| Файл | Что внутри |
|---|---|
| `case.json` | Набор из кейса без изменений (копия `test_data/data.json`): 10 клиентов, 30 услуг, 100 транзакций |
| `demo.json` | 12 демонстрационных клиентов, по одному на каждый сценарий модели (id 101–112, email `demo-…`) |
| `build_demo.py` | Собирает `demo.json` из описания сценариев: `python3 build_demo.py` |

Формат — как у `PUT /api/v1/source/snapshot` и `test_data/001_schema.up.sql`.

## Загрузка

```bash
# Docker
docker compose exec backend python manage.py load_sample             # набор кейса
docker compose exec backend python manage.py load_sample --extended  # кейс + демо-сценарии

# локально, из backend/
python manage.py load_sample --extended
```

Команда заменяет текущие данные целиком и пересчитывает оценки. В Docker каталог
монтируется в контейнер как `/sample-data` (путь меняется переменной `SAMPLE_DATA_DIR`).

## Сдвиг дат

Оба набора рассчитаны на опорную дату кейса **19.10.2026 15:00 UTC**: на неё выставлены
статусы и сроки услуг. В кейсе данные поступают в реальном времени, поэтому при загрузке
все даты сдвигаются так, чтобы опорная дата совпала с текущим моментом. Услуга, которая
в наборе истекает через 2 дня после опорной даты, после загрузки истекает через 2 дня
от «сейчас», в какой бы день ни шла демонстрация. Оценки при этом совпадают с оценками
на опорную дату (это проверяет тест `test_results_do_not_depend_on_load_day`).

## Демонстрационные сценарии

Уровень — при настройках модели по умолчанию. Соответствие проверяет тест
`backend/analytics/tests/test_sample_load.py`.

| id | Сценарий | Уровень |
|---|---|---|
| 101 | prolong_wait и пустой баланс | высокий |
| 102 | Истекает через 12 часов без автопродления, денег нет | высокий |
| 103 | Истекает через день без автопродления, деньги есть | средний |
| 104 | Бонусы заблокированы (bonusState = locked) | средний |
| 105 | То же, но бонусы доступны (bonusState = unlocked) | низкий |
| 106 | Почасовая оплата, баланса хватит меньше чем на сутки | средний |
| 107 | Деньги только на реферальном балансе (withdrawBalance) | средний |
| 108 | Услуга приостановлена (suspended), денег на продление нет | средний |
| 109 | Часто не оплачивает заказы (not_performed) | низкий |
| 110 | Надёжный клиент: годовая услуга с автопродлением | низкий |
| 111 | Без услуг | нет оценки |
| 112 | Только удалённая и заблокированная услуги | нет оценки |

Пары 104/105 и 102/103 удобны для показа жюри: отличается одно условие, и видно,
как оно меняет оценку и текст причины.
